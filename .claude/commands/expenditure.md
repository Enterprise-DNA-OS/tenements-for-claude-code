# expenditure

Spend against commitment this tenement year, tenement by tenement.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs expenditure --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. Lead with the tenements whose year ends soonest with the most still to spend. Nothing here lodges with the department, pays rent or reports to ASX.
