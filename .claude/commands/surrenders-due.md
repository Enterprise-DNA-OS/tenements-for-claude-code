# surrenders-due

Compulsory partial surrenders due before the sixth anniversary, and the ones already lodged.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs surrenders --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. Ask which blocks the geologists want to keep before drafting anything. Nothing here lodges with the department, pays rent or reports to ASX.
