# calendar

Every open date for the next twelve months, with the rule behind each.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs calendar --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. Group by month when the list is long. Nothing here lodges with the department, pays rent or reports to ASX.
