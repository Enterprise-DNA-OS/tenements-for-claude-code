# rents-due

Rent due and not yet paid, with the amount on record.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs rents --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. Rent is due within one month of the anniversary. Lead with anything late. Nothing here lodges with the department, pays rent or reports to ASX.
