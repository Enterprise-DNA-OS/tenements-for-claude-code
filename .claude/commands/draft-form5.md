# draft-form5

Draft the Form 5 working paper: the year's spend by category against the commitment.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs draft-form5 "<tenement>" --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. Say the total, the commitment and any shortfall. The working paper is not the Form 5; it is lodged through Mineral Titles Online. Nothing here lodges with the department, pays rent or reports to ASX.
