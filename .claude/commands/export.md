# export

Archive every record to one JSON file.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs export --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. Say where the file is. It holds the whole register. Nothing here lodges with the department, pays rent or reports to ASX.
