# expiring

Tenements whose term ends in the next twelve months, and any extension on file.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs expiring --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. For each: extend, convert, or let it go. That is the holder's call. Nothing here lodges with the department, pays rent or reports to ASX.
