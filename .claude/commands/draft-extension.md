# draft-extension

Draft the record behind an extension of term application.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs draft-extension "<tenement>" --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. The ground relied on must be one the regulations allow; the tenement adviser confirms it. Nothing here lodges with the department, pays rent or reports to ASX.
