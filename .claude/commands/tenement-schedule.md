# tenement-schedule

The ASX Listing Rule 5.3.3 schedule for a quarter: held, acquired, disposed of, farm-in and farm-out.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs schedule <quarter code> --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. Show each of the five sections, with Nil where empty. Nothing here lodges with the department, pays rent or reports to ASX.
