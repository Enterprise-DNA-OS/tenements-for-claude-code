# form5-due

Form 5s due, including final Form 5s for tenements that have ended.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs form5 --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. Run /draft-form5 for any that are due inside 30 days. Nothing here lodges with the department, pays rent or reports to ASX.
