# applications

Pending applications: what we applied for, when, and how long it has waited.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs applications --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. Name the oldest first. An application appears in the ASX schedule as an application. Nothing here lodges with the department, pays rent or reports to ASX.
