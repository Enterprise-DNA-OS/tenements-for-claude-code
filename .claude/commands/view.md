# view

Render the read-only dashboards: this week, the calendar and spend against commitment.

```bash
npm run view            # week, calendar and spend
npm run view -- week
```

Files land in views/. Open them in a browser or print them. They are read-only: changes happen by asking Claude Code. Say which files were written.
