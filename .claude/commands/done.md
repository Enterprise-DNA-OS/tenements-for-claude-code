# done

Mark an obligation done.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs done <obligation code> --on=<YYYY-MM-DD> --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. Only once it has actually happened. Nothing here lodges with the department, pays rent or reports to ASX.
