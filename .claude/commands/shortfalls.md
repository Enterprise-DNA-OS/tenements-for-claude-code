# shortfalls

Tenements that spent less than their commitment last year, and where the exemption stands.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs shortfalls --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. For any with no exemption lodged, say the date the 60 days ran out or runs out. Nothing here lodges with the department, pays rent or reports to ASX.
