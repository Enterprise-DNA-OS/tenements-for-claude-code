# weekly-review

Draft the Monday tenement review from attention, due and compliance.

Read fresh data. Never invent a tenement, a date, an amount or command output.

```bash
node scripts/tenements.mjs weekly-review --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a tenement number or name is ambiguous, list the candidates and ask. Open the draft, check it reads right, and say where it is. Nothing is sent. Nothing here lodges with the department, pays rent or reports to ASX.
